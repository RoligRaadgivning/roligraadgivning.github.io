# Chris Roliggaard — website v12

This version rebuilds the styling from the original stylesheet instead of stacking successive overrides.

## Visual system
- One typeface across all pages and controls: Plus Jakarta Sans.
- One palette: deep navy, vivid orange, warm white and cool light body text.
- Dark backgrounds throughout the homepage and all interior pages.
- Shared header, buttons, headings, cards, forms and footer.
- Consistent section spacing and responsive layouts.
