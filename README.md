# Chris Stegemejer Roliggaard — hjemmeside v3.0

En ny visuel retning baseret på det vedhæftede design: næsten sort baggrund, varme lyse tekster, diskret gylden accent, serif-typografi i overskrifter, minimalistisk navigation og stort portræt i hero-sektionen.

## Filer
- `index.html` — hele hjemmesidens indhold og struktur
- `styles.css` — design og responsivt layout
- `script.js` — mobilmenu, glidende navigation og dynamisk årstal
- `chris-hero.jpg` — hero-portræt
- `chris-about.jpg` — sekundært portræt, klar til senere brug

## Upload til GitHub Pages
Upload indholdet af denne mappe til roden af dit eksisterende repository, og erstat de tilsvarende filer. Behold filnavnene præcis som de er.

## Mangler før booking kan bruges
- `[MIT GOOGLE CALENDAR-LINK]` i `index.html` skal erstattes med dit faktiske bookinglink. Indtil da er knappen en tydelig pladsholder og booking fungerer ikke.

## Redaktionelle noter
- Designet er tilpasset referencebilledet; indholdet er bygget ud fra de tidligere aftalte oplysninger og dokumenterede resultater.
- Den engelske sprogmarkering er bevidst inaktiv, fordi der ikke er skrevet en engelsk version endnu.
- Tidsrammer, der ikke var bekræftet i input, er ikke opfundet. Resultatcasene viser derfor ikke udokumenterede årstal.
- Eksterne skrifttyper hentes fra Google Fonts. Uden internet bruges serif-/sans-serif-fallbacks.
